# Deprecated Unrefactored Tools

This directory contains scripts that were not aligned with the single-video
official dataset pipeline refactor.

They are preserved for reference and recovery, but they are not recommended
entrypoints. Use `scripts/run_dataset_pipeline.py` for official dataset
production.

Original relative paths are preserved under this directory. For example:

```text
scripts/example.py -> deprecated/unrefactored_tools/scripts/example.py
```

See `manifest.json` for the moved paths.
